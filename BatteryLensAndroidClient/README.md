# BatteryLens Android Client

App Android standalone per BatteryLens v123.

La connessione viene ricercata automaticamente sulla LAN. Il server v123 risponde sulla porta UDP 50042 e restituisce Indirizzo server e Porta di connessione configurati in BatteryLens > Impostazioni.

L'app non apre Chrome o altri browser esterni: mostra l'interfaccia BatteryLens in una WebView Android incorporata nell'APK, senza barra indirizzi o controlli del browser.
